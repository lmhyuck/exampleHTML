> **Vanilla JavaScript**를 활용하여 인스타그램 프로필 페이지의 UI를 구현하고, DOM 조작을 통해 실시간 데이터를 수정할 수 있는 인터랙티브 웹 프로젝트입니다.

---

## 🚀 주요 기능 (Key Features)

### 1. 동적 프로필 편집 (Profile Management)
* **정보 수정**: '프로필 편집' 버튼을 클릭하여 이름, 소개, 링크를 `input` 모드로 전환해 실시간으로 수정할 수 있습니다.
* **ID 변경**: 상단 설정 아이콘을 눌러 계정 아이디(`lmhyuck_00`)를 즉시 변경 가능합니다.
* **이미지 업데이트**: 프로필 사진 클릭 시 이미지 URL을 입력받아 프로필 사진을 교체할 수 있습니다.

### 2. 세련된 UI/UX
* **마우스 오버 효과**: 프로필 사진에 마우스를 올리면 그레이스케일(50%) 효과가 적용됩니다.
* **Grid 레이아웃**: `CSS Grid`를 사용하여 3열 게시물 구조와 상단 메뉴바를 실제 인스타그램과 유사하게 배치했습니다.
* **아이콘 라이브러리**: Font Awesome 6.4.2 버전을 활용한 직관적인 아이콘 UI를 제공합니다.

---

## 🛠 기술 스택 (Tech Stack)

* **언어**: HTML5, CSS3, JavaScript (ES6+)
* **아이콘**: Font Awesome 6.4.2
* **디자인 요소**: CSS Grid (Layout), Flexbox, Object-fit
